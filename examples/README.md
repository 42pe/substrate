# Examples

Example substrates will live here as the project dogfoods itself — the first one
is coming. An example is just a `.substrate/` directory (boards, groups,
`field_schema`, and policies as JSON) you can copy into a project and explore
with `substrate serve`.

For now, the fastest way to see a working substrate is:

```sh
npx @diegoferreyra/substrate init
npx @diegoferreyra/substrate serve
```

which creates a starter board you can inspect at <http://localhost:7475>.
